Materi Komputasi Awan

Mengenal konsep, jenis layanan, manfaat, dan risiko Cloud Computing.

1. Pengertian Cloud Computing

Cloud Computing atau komputasi awan adalah teknologi yang memungkinkan pengguna mengakses sumber daya komputasi seperti server, penyimpanan, database, jaringan, dan perangkat lunak melalui internet.

Dengan teknologi ini, pengguna tidak harus memiliki atau mengelola seluruh infrastruktur komputer sendiri. Layanan dapat digunakan sesuai kebutuhan melalui penyedia layanan cloud.

2. Jenis Layanan Cloud Computing

SaaS

Software as a Service merupakan layanan perangkat lunak yang dapat digunakan melalui internet tanpa harus melakukan instalasi dan pengelolaan aplikasi secara langsung.

Contoh:

  • Google Docs
  • Gmail
  • Microsoft 365

PaaS

Platform as a Service merupakan layanan yang menyediakan platform untuk mengembangkan, menguji, dan menjalankan aplikasi tanpa harus mengelola infrastruktur server secara langsung.

Contoh:

  • Google App Engine
  • Heroku
  • Microsoft Azure App Service

IaaS

Infrastructure as a Service merupakan layanan yang menyediakan sumber daya infrastruktur komputer seperti server virtual, penyimpanan, dan jaringan melalui internet.

Contoh:

  • Amazon EC2
  • Google Compute Engine
  • Microsoft Azure Virtual Machines

3. Manfaat Cloud Computing

  • Menghemat biaya pembelian dan pemeliharaan perangkat keras.
  • Dapat diakses dari berbagai tempat selama terhubung internet.
  • Memudahkan penyimpanan dan pengelolaan data.
  • Mudah menyesuaikan kapasitas sesuai kebutuhan.
  • Mendukung kolaborasi dan pekerjaan secara online.

4. Risiko Cloud Computing

  • Ketergantungan terhadap koneksi internet.
  • Risiko kebocoran dan penyalahgunaan data.
  • Gangguan layanan dari penyedia cloud.
  • Ketergantungan terhadap penyedia layanan.
  • Biaya penggunaan dapat meningkat sesuai kebutuhan.
